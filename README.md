# Biblioteca Digital

Plataforma web orientada al descubrimiento, reseña y gestión e interacción con contenido literario de forma intuitiva, ágil y segura.

---

## Descripción General

Esta plataforma ha sido diseñada para ofrecer un espacio interactivo donde el usuario pueda explorar un catálogo de obras, gestionar su perfil personal, interactuar mediante reseñas y acceder a contenidos en formato digital.

El sistema combina una experiencia visual limpia con una arquitectura backend enfocada en la seguridad, eficiencia y protección de los datos de cada usuario.

---

## Funcionalidades Principales

### Exploración de Catálogo y Libros
* **Catálogo interactivo:** Navegación fluida por las distintas obras disponibles.
* **Detalle de obras:** Consulta de información específica de cada libro.
* **Visualización de PDF:** Lectura e inspección segura de documentos integrados directamente en la plataforma.
* **Descarga del PDF:** Para tener una copia local del mismo.

### Sistema de Reseñas y Calificaciones
* **Publicación de reseñas:** Los usuarios pueden compartir sus opiniones sobre los libros.
* **Edición y eliminación en tiempo real:** Control total para gestionar, modificar o retirar las opiniones publicadas.
* **Calificación por estrellas:** Evaluación rápida del contenido.

### Gestión de Usuarios y Cuenta
* **Registro e Inicio de Sesión:** Creación de cuenta con validaciones de seguridad avanzadas en contraseña.
* **Panel de Usuario (`Cuenta`):** Gestión del perfil personal y control sobre las actividades realizadas en la plataforma.
* **Ajustes de Seguridad:** Funciones integradas para cambio seguro de contraseña y opción de eliminación de cuenta.

### Secciones Legales e Informativas
* Navegación por pestañas interactivas para revisar términos, políticas y soporte, en caso de que se necesite.

---

## Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6).
* **Backend:** PHP
* **Base de Datos:** MySQL
* **Servidor Web:** Apache
